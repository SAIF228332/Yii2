# MessageBox — личный кабинет сообщений

Учебный проект на HTML + CSS.

## О проекте

MessageBox — простой макет личного кабинета пользователя с возможностью просмотра сообщений, отправки нового сообщения и просмотра статистики.

Проект специально сделан без JavaScript и backend-части, чтобы его было удобно в дальнейшем перенести на **Yii2 + PHP**.

## Страницы

- `index.html` — личный кабинет;
- `messages.html` — входящие и отправленные сообщения;
- `send-message.html` — форма отправки сообщения;
- `statistics.html` — статистика сообщений;
- `css/style.css` — общие стили проекта.

## Технологии

- HTML5
- CSS3
- Адаптивная верстка
- Семантическая структура

## Как открыть

1. Скачайте или клонируйте репозиторий.
2. Откройте папку проекта в PhpStorm.
3. Откройте `index.html` в браузере.

## Публикация на GitHub

Создайте новый репозиторий на GitHub, например `message-cabinet`, затем выполните в терминале проекта:

```bash
git init
git add .
git commit -m "Создан проект личного кабинета сообщений"
git branch -M main
git remote add origin https://github.com/ВАШ-ЛОГИН/message-cabinet.git
git push -u origin main
```

## Дальнейший перенос в Yii2

В будущем страницы можно разделить на Yii2 views, а общую навигацию вынести в layout. Статические данные заменить данными из PHP-моделей и базы данных.
